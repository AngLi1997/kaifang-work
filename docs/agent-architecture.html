一次任务的调用链

  1. 用户在输入区描述目标，壳层创建任务并收集工作空间与附件上下文
  2. 主进程启动基础 Agent 会话，写入 sessions
  3. 基础 Agent 规划步骤，按工具描述选择插件工具
  4. 插件运行时校验版本、参数、权限与工作空间范围
  5. 插件执行领域逻辑，调用 Sidecar、工作空间文件或外部系统
  6. 结构化结果、来源与产物路径回写存储，文件落到 artifacts/
  7. 执行事件持续回传渲染层，逐条增量渲染为事件块
  8. 高风险步骤进入待确认，批准或拒绝后继续
  9. 任务完成生成摘要：目标、范围、结果、失败项、下一步

分层约束

  1. 渲染层不直接访问 Node.js、文件系统与敏感系统 API
  2. 基础 Agent 只保留对话、上下文、工具调用与 Harness
  3. 行业规则只存在于插件工具，可独立发布、测试、授权
  4. Sidecar 不暴露给基础 Agent，不决定任务流程
  5. 凭证只在主进程与 Keychain 之间流动
  6. 不可逆操作、批量修改与外部写入必须确认并留痕
